# 收件箱 · 待处理入口

> **这个文件夹的功能是"预处理分类"，不是存储。** 它应当经常是空的。

## 怎么用

1. 新下载 / 新收到的任何文件，**先丢进来，不用当场判断**。
2. 在对话里涉及本项目时，AI 会主动扫描本目录，对每个文件给出：**建议归属层 → 具体子目录 → 是否与已有文件重复 → 建议文件名**。
3. **分类移动为自动执行**；**改名与删除需你确认**（先给理由与受影响清单，等你点头）。
4. 处理完的文件移出本目录，本目录重新为空。

## 分派去向速查

| 文件性质 | 去向 |
|---|---|
| 外文论文 / 中文论文 / 厂商手册（原始件） | `01-原始文献\` → 对应子目录 |
| 某篇文献的中文翻译 | `02-加工与沉淀\1-文献翻译\` |
| 某篇文献的笔记、总结 | `02-加工与沉淀\2-文献总结\` |
| 概念精讲 / 跨文献的方法论、知识体系 | `02-加工与沉淀\3-知识精讲\` |
| 暂难归类 | `02-加工与沉淀\4-其他\` |
| 按时间汇总的科研简报 | `03-每日简报\<年-月>\` |
| 周报 / 月报 / 专利 / 正式交付 | `04-对外交付\` → 对应子目录 |
| 约束 AI 行为的规则、写作规范 | `00-AI协作规范\` |
| 提取文本、raw txt、脚本、流水线中间件 | `99-临时文件\` |

## 判断优先级（一份文件看着能进多个地方时）

1. **它是原始输入，还是经过加工的东西？** → 原始进 `01`，加工过的不进 `01`
2. **加工物是贴着原文（翻译）、绑定单篇（总结），还是可脱离原文（精讲）？** → `02` 内的一/二/三级
3. **它是按时间汇总的一段时间的工作吗？** → `03-每日简报`
4. **它是对外交付物，还是对内自用？** → 对外 `04`
5. **它是给人用的，还是给机器用的中间态？** → 机器中间态 `99`
6. **它约束的是"产出过程"本身吗？** → 是则 `00`

拿不准时不要猜：列入"待你决定"清单，而不是自行归类。

## 入库后会自动接着做什么

- 英文文献 → 自动生成中文全文翻译（`02-加工与沉淀\1-文献翻译\`）
- 中英文均 → 更新初印象卡（总览 + 类型目录）
- 最后 → 重跑检索索引（由 litbuddy 的 `tools\build_search.py` 重新生成，见系统 README §三）

**中文文献到此为止**——只建卡，不做自动加工。
