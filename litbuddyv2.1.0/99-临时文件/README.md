# 99-临时文件 · 机器中间态

> **判据**：给人看无意义、给机器用的东西。**不是知识层**，不属于任何加工环节。

## 这里放什么

- PDF 提取出的文本（`*_extract.txt`、`*.txt`）
- 一次性脚本（`_probe_*.py`、`_extract.py`）
- 流水线中间件（`final_draft.md`、`pipeline-state.yaml`）
- 检索任务记录：`lit-<日期>-<主题>\`（四件套见下）
- 旧版本归档（如被替换的初印象卡、卸载备份）

## 检索任务记录目录

```
99-临时文件\lit-<日期>-<主题>\
├── task-context.yaml      ← 目标、范围、约束、判定标准
├── search-log-<时间戳>.md ← 检索式与每步结果
├── source-audit-<日期>.md ← 题录核验、DOI 解析、全文合法性
├── state-history.log      ← 状态变更流水
└── extract\               ← 提取文本 / 页面图 / 中间脚本
```

任务结束后**整体保留**，不删除——它是可追溯的凭证。

## 为什么单独成层

它既能随时取用，又**不会污染正式结构**。把 raw txt 混进 `02-加工与沉淀\` 会让"人的加工产物"和"机器中间态"分不开。

## 清理约定

- **不在整理任务中顺手清理**本层。要清理，先报告清单、等用户确认。
- 归档类内容（如 `初印象卡_旧版归档-<日期>\`）按"日期后缀"命名，便于识别新旧。
