# 每日简报 · 模板

> 使用前先读技能内 `references\09-每日简报规范.md`。
> **视角是第一人称"我"**，读者是用户本人，不是 AI。

---

## 文件位置与命名

```
03-每日简报\<YYYY-MM>\<覆盖区间结束日> 科研简报.md
```

例：`03-每日简报\2026-09\2026-09-22 科研简报.md`

---

## 模板

```markdown
> 覆盖区间：<YYYY-MM-DD> ~ <YYYY-MM-DD>（单日可省此行）

<YYYY.MM.DD> 总览：<一段话>

摘要：一、<文献名>——<价值判断 + 讨论了什么>
     二、<文献名>——……
```

---

## 填写指引

### 总览（必写，一段话）

必须回答两件事：

1. **本周期新增了几篇文献**（按类型说：国内学位论文 / 期刊论文 / 国外论文 / 厂商资料）
2. **主要聊了哪些思路、知识或概念**

> 2026.09.20 总览：我新增了 3 篇国内学术论文到系统中，重新梳理和总结了过往成功的科研思路，简要探讨了目前实现阻抗匹配主流的几种方式并分析了其中优劣。

### 摘要（必写，分条）

每一项 =
**文献名** + **我对它的价值判断**（契合 / 不契合 / 值得精读 / 只宜当资料）+ **我与 AI 讨论了什么、得出什么结论**。

> 摘要：一、初读了博士论文'阻抗匹配机理及 Z 阻抗网络变换器构造_张桂东'，这篇论文与我目前的研究方向并不契合，但我发现论文绪论引言部分提到了电力电子技术近年来发展的全貌，作者将整个电力电子技术抽象为"设计可实现电能高效变换的变换器"，并提出软开关变换器、PWM 整流器、多电平变换器、高增益 DC-DC 变换器和 Z 源变换器等是其发展的主要形式，随后我与 ai 深入探讨了这几类变换器的异同。
>
> 二、初读了硕士论文'等离子体负载射频电源阻抗匹配系统硬件平台设计与实现_李光俊'，本篇论文对于还处于初学阶段的我很有研读价值，论文绪论部分详细介绍了射频电源的发展历程，在第二章，作者系统且通俗的介绍了等离子体负载特性、反射功率等核心指标和阻抗匹配设计的基本方法，在论文的后半部分，详细阐述了如何搭建一个真正的软硬件平台完成设计。总而言之，本论文由于与我本人的研究方向高度重合，其背景知识和研究方法都有很高的借鉴价值。

## 检查项

| 检查项 | 标准 |
|---|---|
| 是否用第一人称"我"？ | 出现"AI 帮用户…" → 改写 |
| 有没有价值判断？ | 通篇无判断 → 补（这是简报的核心价值） |
| 是不是流水账？ | 出现"改文件 / 跑脚本 / 重建索引" → 删掉或压缩成一句 |
| 日期是否用了覆盖区间的结束日？ | 否 → 改正 |
| 跨天是否写了覆盖区间？ | 跨天未写 → 补在文件头 |
| 是否有未解问题被漏掉？ | 有疑问却没写 → 补一句 |

## 反例
