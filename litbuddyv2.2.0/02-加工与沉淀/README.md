# 02-加工与沉淀 · 加工物与沉淀物

> **判据**：凡是对 `01-原始文献\` 里的材料做过加工、或由多份材料提炼出来的东西，都在这一层。
> **不在这一层**：未经加工的原件（→ `01-原始文献\`）｜机器中间态（→ `99-临时文件\`）｜对外交付（→ `04-对外交付\`）。

## 内部结构：按"基本点"分五类

```
02-加工与沉淀\
├── 1-文献翻译\      ← 英文文献的中文全文对照翻译（含原文图提取）
├── 2-文献总结\      ← 以「文献」为基本点：某篇文献的通盘总结与笔记
├── 3-知识精讲\      ← 以「抽象概念 / 知识体系」为基本点：某某知识、某某板块的精讲
├── 4-其他\          （暂空，缓冲）
└── 5-文献串讲\      ← 以「多篇文献（≥2）」为基本点：技术路线演化网（带页码溯源）
```

**主轴是"加工深度"**：`翻译 → 总结 → 精讲` 是"对同一批材料做得越来越深"的序列；`5-文献串讲` 跨多篇收束成演化网，是最深一档（多对一）。`4-其他` 是缓冲位，不属于深度序列。

## 五类的判据（按顺序问）

| 子目录 | 基本点 | 自检问句 |
|---|---|---|
| `1-文献翻译` | 原文 | 这是**整篇外文文献**的中文对照翻译吗？ |
| `2-文献总结` | **文献（单篇）** | 这个产物能否命名为"《某某文献》总结 / 笔记"？ |
| `3-知识精讲` | **抽象概念 / 知识体系** | 这个产物能否命名为"《某某概念 / 某某板块》精讲"？ |
| `4-其他` | — | 都不符合时暂放此处，**并列入"待你决定"**，不要硬塞 |
| `5-文献串讲` | **多篇文献（≥2）** | 这是"这几篇怎么连成一条技术路线"的演化网吗？（按 `references\10`） |

**两条边界规则**

1. **同一篇文献可同时产出 `2-文献总结` 与 `3-知识精讲`**，两者不互斥——前者讲清"这篇做了什么"，后者讲透"其中某个概念是什么、为什么需要它"。
2. **跨多篇的演化脉络归 `5-文献串讲`，跨多篇的抽象概念归 `3-知识精讲`**——前者以文献为节点、带页码溯源；后者脱离原文独立阅读、不带页码。

## `1-文献翻译`

**只做英文文献**，严格套用 `模板\翻译模板.md`：双语标题 → 题录块 → 术语对照表 → 锚点索引 → 逐段 `**Original:**` / `**中文:**` 对照（每段带 `Source: p.x Sxxx` 便于溯源）→ **图嵌入 + 双语图注**（原文图按 `references\02` 图提取三层落到 `_插图\<产物名>\`）→ 原文关键词逐字照录 + 中文关键词 → 阅读提示（含"未解决与未提及"）→ 页脚元信息。

命名：`<原文要点>_中文翻译.md`。**中文文献不做翻译**（只建初印象卡）。

## `2-文献总结`

对**整篇文献**的通盘理解。常见形态：黑箱理解（先懂"做什么/怎么做/结果如何"）、双语精讲、逐节笔记。

命名：`<文献简称>_<形态>.md`，如 `Stanford2025_FTMN_黑箱理解.md`。

> 本层产物**标准与 `04`/`08` 共用**（落位判据见技能 `references\04` 末尾）：回答结构、阅读提示含"未解决与未提及"（读文献四问之Ⅳ）、插图按 `02` 图提取三层。入库流水线的**自动**总结步骤尚未启用（`入库总结` 键 `开` 按 `关` 处理并提示一次）；用户显式要求写总结时照常产出。

## `3-知识精讲`

从文献中提炼出的**可独立阅读的概念讲解**。规则见技能内 `references\08-知识精讲规范.md`。

**硬骨架四要素**：① 问题动机 ② 对照/取舍表 ③ 映射到本项目 ④ 下一步。
**红线**：精讲**不带页码**（这是它与文献串讲的分水岭；证据性图注注明文献页码不受限）。
**插图**：原文提取图（证据）与自绘示意图（讲解）均可，**图源必标**。

命名：`<概念或板块>_知识精讲.md`。

## `5-文献串讲`

多篇文献（≥2）连成的**技术路线演化模型**（演化网：承接 / 并行竞争 / 并行互补）。规则见技能内 `references\10-文献串讲规范.md`，模板 `模板\串讲模板.md`。

命名：`<主题>_技术演化串讲.md`。**必须页码/段落溯源**。

## `4-其他` 与缓冲纪律

- `4-其他\` 是缓冲位，**不是分类**。放进去的东西必须同时列入"待你决定"清单，等用户拍板后再归位。

## 注意

- 同一原文的两份**平行译文不算重复**：正式译文留本层，其余留档 `99-临时文件\`。
- 中文文献不产出翻译，也不做**自动**加工；相关讨论由「文献问答」承接，结论结晶进 `3-知识精讲\`。
