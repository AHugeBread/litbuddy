# 04-对外交付 · 对项目的正式产出

> **判据**：有**接收方**的正式产出。对内自用的不放这里。

## 内部结构

```
04-对外交付\
├── 周报月报\      ← 给导师/团队的工作汇报
└── 专利\         ← 专利交底书等
```

## 约定

- 汇报**如实反映**：学习、理解、验证、未解问题、下一步。专业 ≠ 夸大。
- 源文件（草稿、排版中间态）放 `99-临时文件\`，**只有最终交付物**放这里。
- 同目录下可保留 `.docx` 等交付格式与 `.md` 源文件。

> 若不适用，整层可删——它是可选的交付层，不影响系统其余部分运行。
