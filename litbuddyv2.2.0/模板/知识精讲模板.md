# 知识精讲 · 模板

> 使用前先读技能内 `references\08-知识精讲规范.md`。
> **四要素必写**：① 问题动机 ② 对照/取舍表 ③ 映射到本项目 ④ 下一步。
> **红线**：精讲**不带页码**（带页码说明写成了索引）。

---

## 通用抬头（三选一后接对应骨架）

```markdown
# <概念 / 板块名> · 知识精讲

> **主题**：<一句话说清这份精讲在讲什么>
> **粒度**：单概念深挖 ｜ 多概念对比 ｜ 框架级理解
> **来源**：讨论于 <日期>；触发文献（可选）：<F-0x / D-0x 简称>
> **关联**：<库内其他精讲或文献，编号 + 简称；没有就删掉此行>
```

---

## 索引 / Index（产物必带，v2.1.2 起）

抬头块之后、正文第一节之前插入目录段；每个 `## ` 小节标题前放置锚点 `<a id="K01"></a>`（编号连续），目录用跳转链接列出全部小节：

```markdown
## 索引 / Index
- [一、为什么需要它](#k01)
- [二、核心定义与公式](#k02)
- [三、机制：它是怎么发生的](#k03)
- [四、生活类比](#k04)
- [五、后果与代价](#k05)
- [六、解决方案有哪几条路](#k06)
- [七、映射到本项目](#k07)
- [八、一句话总结](#k08)
- [九、下一步](#k09)

<a id="K01"></a>
## 一、为什么需要它
…（正文，逐节前置锚点 K02、K03…）
```

（骨架 B/C 的小节不同，按**实际小节**生成目录；条目与小节一一对应。索引是结构导航，**不写页码**——"不带页码"红线不变。）

## 骨架 A · 单概念深挖

适用：把**一个概念**讲透（如"功率反射""Q 值""镜像阻抗"）。

```markdown
# <概念> · 知识精讲

> 主题：… ｜ 粒度：单概念深挖 ｜ 来源：…

## 一、为什么需要它
<问题动机。先讲出现了什么工程问题、此前的方法为何不够用。**不从定义开始。**>

## 二、核心定义与公式
<一句话定义 + 关键公式。公式用纯文本写清符号含义。>

## 三、机制：它是怎么发生的
<物理过程 / 推导直觉。讲"为什么会有这个现象"。>

## 四、生活类比
<可选的，但强烈建议。用一个日常场景把机制说通。>

## 五、后果与代价
<这个现象/机制会带来什么问题。>

## 六、解决方案有哪几条路
| 路线 | 做法 | 优点 | 代价 | 失效条件 |
|---|---|---|---|---|

## 七、映射到本项目
<它在当前研究里处于什么位置、影响哪个模块（如 PA / 匹配网络 / 控制）。>

## 八、一句话总结
<一段话收尾。>

## 九、下一步
<接下来该做什么 / 该看哪一篇 / 该验证什么。>
```

## 一、分类逻辑
<按什么维度分？为什么这样分？>

## 二、逐项展开

### 2.1 <方案 A>
- **结构**：…
- **原理**：…
- **优点**：…
- **缺点**：…
- **适用场景**：…

### 2.2 <方案 B>
（同上五段式，**格式必须一致**，便于横向对比）

<什么条件下选哪个。给出判定顺序，不要写"看情况"。>

## 五、映射到本项目
<针对本项目（约束现状见项目 `00-AI协作规范\`）该怎么选。>

## 六、下一步

## 填写指引

| 检查项 | 标准 |
|---|---|
| 第一段是不是"问题动机"？ | 若不是，删掉重写 |
| 有没有对照/取舍表？ | 无 → 补一张 |
| 有没有写失效条件与代价？ | 无 → 补（**禁止写成普适最优**） |
| 有没有"映射到本项目"？ | 无 → 补 |
| 有没有"下一步"？ | 无 → 补 |
| 出现页码了吗？ | 出现 → 删掉（那是「文献串讲」的活） |
| 是不是从定义开始、堆术语？ | 是 → 重写为"为什么需要它" |
