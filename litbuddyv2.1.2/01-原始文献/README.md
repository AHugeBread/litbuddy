# 01-原始文献 · 外部输入，未经加工

> **判据**：拿进来是什么样就是什么样。**加工过的任何东西都不放这里。**

## 内部结构

```
01-原始文献\
├── 文献初印象卡（总览）.md      ← 全局总目录（覆盖全部文献）
├── 国内技术论文\
│   ├── 文献初印象卡.md
│   ├── 学位论文\
│   ├── 期刊论文\
│   └── 专利\
├── 国外技术论文\
│   └── 文献初印象卡.md
└── 厂商规格说明书\
    └── 文献初印象卡.md
```

**来源维度**是允许叠加在"加工深度"主轴上的唯一第二维度——检索时两个维度都会用。

## 编号体系

| 前缀 | 类别 |
|---|---|
| `F-01…` | Foreign · 国外技术论文 |
| `D-01…` | Domestic · 国内技术论文（下分 学位论文/期刊论文/专利） |
| `M-01…` | Manufacturer · 厂商规格说明书 |

## 三条约定

1. **默认保持原文件名。** 既有笔记与引用都用这些名字，改名会导致跟丢。
2. **初印象卡两处同步。** 新增一篇 → ①总览加一条；②对应类型目录加同一条。只改一处 = 卡体系失效。
3. **不做关联网络。** 只按篇名一篇篇排开（详见 `模板\初印象卡模板.md`）。

## 跨领域迁移

来源子层可整体替换成该领域更自然的分类（如"经典教材 / 顶会论文 / 工业报告"），**但"按加工深度排层"的主轴不变**，编号体系可按需改造。
