# 03-每日简报 · 给"我"看的科研记录

> **这一层与 `.workbuddy\memory\` 是两套东西，不要混。**
> - `.workbuddy\memory\YYYY-MM-DD.md` = **AI 视角**的工作日志（做了什么、产出在哪、未做什么），**给 AI 看**，用于跨会话续接。
> - `03-每日简报\` = **用户视角**的科研简报（我读了什么、聊了什么概念、得出什么结论），**给用户看**，用于回顾"上个周期我干了什么"。
>
> 前者是后者的**素材源**，但视角必须重写。

## 结构：按月归档

```
03-每日简报\
└── <YYYY-MM>\
    └── <覆盖区间结束日>.md
```

- **按月建子文件夹**，便于按周/月翻阅。
- **单篇简报可以覆盖一天或好几天**——科研不是每天都发生，不必强求每天一份。
- 单篇以**覆盖区间的结束日**命名（如 `2026-09-22.md`）；若跨天，在文件头写明实际区间。

> 📌 **"上次覆盖到哪"不在这里** —— 它是**状态**，记在 `00-AI协作规范\_状态.md` 的 `水位线` 键里（连同"对话/自动"触发方式）。
> 为什么搬到那里：状态集中存放，更新程序才不必逐个文件去判"谁去谁留"。定义见技能内 `references\15-项目状态清单.md`。

## 单篇格式

```
<YYYY.MM.DD> 总览：<一段话——本周期新增了几篇文献、主要聊了哪些思路/知识/概念>

摘要：一、<文献名>——<我对它的价值判断 + 与 AI 讨论了什么>
     二、<文献名>——……
```

示例：

> 2026.09.20 总览：我新增了 3 篇国内学术论文到系统中，重新梳理和总结了过往成功的科研思路，简要探讨了目前实现阻抗匹配主流的几种方式并分析了其中优劣。
> 摘要：一、初读了博士论文'阻抗匹配机理及 Z 阻抗网络变换器构造_张桂东'，这篇论文与我目前的研究方向并不契合，但我发现论文绪论引言部分提到了电力电子技术近年来发展的全貌……随后我与 ai 深入探讨了这几类变换器的异同。二、初读了硕士论文'等离子体负载射频电源阻抗匹配系统硬件平台设计与实现_李光俊'，本篇论文对于还处于初学阶段的我很有研读价值……总而言之，本论文由于与我本人的研究方向高度重合，其背景知识和研究方法都有很高的借鉴价值。

**写法要求**：第一人称、写**判断**而非目录、**不写流水账**。规则详见技能内 `references\09-每日简报规范.md`。

## 触发

默认由对话触发：每次对话开始时比对 `00-AI协作规范\_状态.md` 的 `水位线` 与 `.workbuddy\memory\` 中的日期日志；有新日志才生成，**至多每天一份**。
（若已改为定时自动化，则由 WorkBuddy 定时任务负责，对话触发整体跳过 —— 见 `_状态.md` 的 `简报触发` 键。）

## 维护

- `水位线` **只在简报成功生成后才推进**，且不允许倒退。
- 不手工编辑历史简报（它是当时认知的快照）；要修正就在新一篇里说明。
