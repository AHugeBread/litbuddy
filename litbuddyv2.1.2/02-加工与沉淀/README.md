# 02-加工与沉淀 · 加工物与沉淀物

> **判据**：凡是对 `01-原始文献\` 里的材料做过加工、或由多份材料提炼出来的东西，都在这一层。
> **不在这一层**：未经加工的原件（→ `01-原始文献\`）｜机器中间态（→ `99-临时文件\`）｜对外交付（→ `04-对外交付\`）。

## 内部结构：按"基本点"分四类

```
02-加工与沉淀\
├── 1-文献翻译\      ← 英文文献的中文全文对照翻译
├── 2-文献总结\      ← 以「文献」为基本点：某篇 / 某些文献的总结与笔记
├── 3-知识精讲\      ← 以「抽象概念 / 知识体系」为基本点：某某知识、某某板块的精讲
└── 4-其他\          （暂空，缓冲）
```

**主轴仍然是"加工深度"**：`翻译 → 总结 → 精讲` 是一条"对同一批材料做得越来越深"的序列。
原 `02-文献加工`（一对一）与 `03-沉淀与结论`（多对一）合并为此层，用一个更贴近实际检索习惯的顺序取代了原来的两分。

## 四类的判据（按顺序问）

| 子目录 | 基本点 | 自检问句 |
|---|---|---|
| `1-文献翻译` | 原文 | 这是**整篇外文文献**的中文对照翻译吗？ |
| `2-文献总结` | **文献** | 这个产物能否命名为"《某某文献》总结 / 笔记"？ |
| `3-知识精讲` | **抽象概念 / 知识体系** | 这个产物能否命名为"《某某概念 / 某某板块》精讲"？ |
| `4-其他` | — | 都不符合时暂放此处，**并列入"待你决定"**，不要硬塞 |

**两条边界规则**

1. **同一篇文献可同时产出 `2-文献总结` 与 `3-知识精讲`**，两者不互斥——前者讲清"这篇做了什么"，后者讲透"其中某个概念是什么、为什么需要它"。
2. **跨多篇的抽象概念必然归 `3-知识精讲`**，不归 `2-文献总结`。

## `1-文献翻译`

**只做英文文献**，严格套用 `模板\翻译模板.md`：双语标题 → 题录块 → 术语对照表 → 锚点索引 → 逐段 `**Original:**` / `**中文:**` 对照（每段带 `Source: p.x Sxxx` 便于溯源）→ 图表双语 → 原文关键词逐字照录 + 中文关键词 → 阅读提示 → 页脚元信息。

命名：`<原文要点>_中文翻译.md`。**中文文献不做翻译**（只建初印象卡）。

## `2-文献总结`

对**整篇文献**的通盘理解。常见形态：黑箱理解（先懂"做什么/怎么做/结果如何"）、双语精讲、逐节笔记。

命名：`<文献简称>_<形态>.md`，如 `Stanford2025_FTMN_黑箱理解.md`。

## `3-知识精讲`

从文献中提炼出的**可独立阅读的概念讲解**。规则见技能内 `references\08-知识精讲规范.md`。

**硬骨架四要素**：① 问题动机 ② 对照/取舍表 ③ 映射到本项目 ④ 下一步。
**红线**：精讲**不带页码**（这是它与"文献串联"的分水岭）。

命名：`<概念或板块>_知识精讲.md`。

## `4-其他` 与未实现模块

- `4-其他\` 是缓冲位，**不是分类**。放进去的东西必须同时列入"待你决定"清单，等用户拍板后再归位。
- **`文献串联` 为未实现模块**（用户对既有产出不满意，待补足约束后再开发）。届时落位为 `5-文献串联\`，**现在不建目录、不写规则**。

## 注意

- 同一原文的两份**平行译文不算重复**：正式译文留本层，其余留档 `99-临时文件\`。
- 中文文献不产出翻译，也不做**自动**加工；相关讨论由「文献问答」承接，结论结晶进 `3-知识精讲\`。
